MerchBee

Interaction Design, Prototyping, Visual Design

The project goal was to have MerchBee to be a "one-stop shop" for everything an Amazon merchant needs to grow their business.
It was a freelance project and the client came to me with some desktop-screen wireframes of the software. I helped improve the existing wireframes and created wireframes for the mobile. Then I created the visual designs and implemented a mockup in html/ css. I designed four sections of the system – email builder, feedback monitoring, sign up, my account. My role included creating:

  • Interaction Design
  • Visual Design
  • HTML Prototype

A Minimalistic Dashboard

The Dashboard of this SaaS did not require a lot of different widgets. Based on my client's wireframe, I created a design for the Dashboard, which I refined into a minimalistic design over a few iterations.

Responsive Design

We decided the desktop required the priority over the mobile screens. However, I made sure the different UI components I chose can fit across all screen sizes, especially the small mobile screens.

UI Components

This software had a lot of pages and consisted of long forms and data tables. I had to design the mobile screens carefully to maintain the hierarchy. We tried to keep the forms as minimal as possible. However, there was one very long form. I made sure the user got alert for any mistake as they fill out each field. We also created templates so that users do not have to create an empty form every time.

Visual Design

As I mentioned in the beginning, I worked on four sections of this software. These sections had different roles and I designed and improved the pages over the time. I used Adobe Photoshop and Illustrator for the visual designs.

I created a simple style guide in HTML for the front-end developer so that he can use and update it with ease.

Although it was not part of the JD, I suggested some improvements to the logo, and the client happily accepted those.

Interactive Prototype

Time constraint was one of the challenges for this project. I worked with one back-end and one front-end developer on this project. To make life simpler for the devs, I created the interactive, responsive mockup with Bootstrap 3 which they used as the skeleton for further development.
